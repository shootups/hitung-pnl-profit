Saya membuat sebuah website sederhana yang berfungsi untuk menghitung persentase dengan cepat dan mudah. Website ini membantu pengguna mengetahui hasil persen dari suatu jumlah uang atau angka tertentu tanpa perlu menghitung manual.

Contohnya, jika pengguna memasukkan nilai **1000 USD** dan memilih **10%**, maka website akan otomatis menghitung hasilnya menjadi **100 USD**.

Website ini dibuat dengan tampilan yang simpel, ringan, dan mudah digunakan untuk kebutuhan sehari-hari, terutama dalam perhitungan keuangan, trading, bisnis, maupun belajar matematika dasar.
